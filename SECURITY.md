# Security

## Reporting a vulnerability

Report it privately through GitHub's private vulnerability reporting: on this repository, open **Security**, then **Report a vulnerability**. Only the maintainers can read the report.

Never open a public issue, pull request or discussion about a vulnerability, and never include a secret or anyone's personal data in a report beyond what is needed to reproduce the problem.

## What is supported

| Part | Supported |
|---|---|
| The platform, as deployed from `main` to learningroutes.com | Yes |
| Older commits, branches and forks | No |

## What to expect

We acknowledge a report within **5 business days** and send a status update within **14 days**, then keep you informed until it is fixed. Please give us that time before saying anything in public.
