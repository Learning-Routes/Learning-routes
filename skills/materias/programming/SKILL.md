Use this to plan, write or review a programming route.

**Settle first**: the language and version (Python 3, JavaScript in the browser…) and what students want to build. If the creator has not said, ask, one question at a time.

**Where learners get stuck**
- `=` read as equality, as in maths, so `x = x + 1` looks impossible. It is assignment; `==` compares.
- A variable imagined as holding several values at once, or as linked forever to the one it was copied from.
- Expecting the computer to understand intent: "it should know what I meant".
- Order of execution: code runs line by line, a function runs only when called, a loop's body repeats.
- Confusing `print` (shows) with `return` (gives a value back).
- Error messages felt as failure instead of read as clues.

**Exercises and blocks**
- code_playground: small runnable code with expected_output. Ask to predict the output before running, then change one line.
- example: a traced example showing the value of each variable line by line.
- check: "what does this print?", with wrong options from the mistakes above.
- fill_blank with match "exact" for code: a missing line or operator.
- drag_drop (Parsons problem): put shuffled lines into a working program.
- scenario for debugging: a bug, several fixes, what each does.

**Beginner sequence**: output and values; variables and assignment; conditions; loops; functions; lists; then a small project that uses all of them. Every lesson: read code, predict, run, modify, then write a little.

**Pitfalls for you**
- Name the language and version in the lesson, and write only code valid in it.
- Run every example in your head line by line and check that expected_output matches exactly, spaces and line breaks included.
- Keep examples short (under about 15 lines) and use the creator's names and comments as they wrote them.
- When the creator's explanation has a technical error, say it plainly and ask before changing it. E.g. "En Python, `=` no compara: asigna un valor. Para comparar se usa `==`."
- Don't recommend a library or a feature you are not sure exists in that version.
