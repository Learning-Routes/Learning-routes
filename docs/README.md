# Project documents

The project's working record. Nothing in the app reads these files. Code comments cite them by
filename (for example `WP10_DESIGN.md §3`), and the names are unchanged, so searching for a name
finds its file.

| Folder | What is in it |
|---|---|
| `prompts/` | The owner's briefs, `PROMPT_NN_*.md`, one per package |
| `handoffs/` | What each package delivered, how it was proven, and what it left open (`WP*_HANDOFF.md`, `CI2_HANDOFF.md`, `WP18_RESUME.md`) |
| `audits/` | Full-codebase audits and the findings each package deferred (`AUDIT*.md`, `FINDINGS_WP*.md`) |
| `design/` | Standing design decisions and contracts (`WP10_DESIGN.md`, `WP6_CONTRACT.md`) |
| `roadmap/` | The roadmap and its revisions |
| `ops/` | Deploy and verification checklists |
| `superpowers/` | Specs and plans written before implementation |
| `archive/` | Notes from an April working session, kept for history and no longer current |
